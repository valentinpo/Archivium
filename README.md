# 📦 Archivium

**Архив и аналитика контента чатов и каналов MAX**

Бот для мессенджера **MAX**, который автоматически выгружает посты и комментарии из чатов и каналов, а затем помогает вести их: статистика, поиск по истории, готовые отчёты.

</div>

---

## ✨ Возможности

- **Автовыгрузка истории** — когда бота добавляют в канал/чат и назначают администратором, он скачивает **всю историю** постов и комментариев (события `bot_added`, `bot_admin_permissions_changed`).
- **Работа с несколькими чатами** — данные каждого канала хранятся отдельно.
- **Новые посты в реальном времени** — подхватываются через long polling (`message_created`).
- **Скачивание вложений** — изображения, видео, файлы сохраняются локально.
- **Статистика для ведения контента** — топ авторов, ключевые слова, активность по дням.
- **Отчёты** — Excel (многостраничный) и красивый HTML с графиками.
- **Поиск** — по тексту, автору, периоду и чату (регистронезависимый, с кириллицей).
- **Графический интерфейс** — простой и современный (тёмная тема).

Без внешних зависимостей — только стандартная библиотека Python.

## 🚀 Установка и запуск

### 1. Создайте бота на платформе MAX

1. Зарегистрируйтесь и верифицируйте профиль на [business.max.ru/self](https://business.max.ru/self) (нужен профиль организации, ИП или самозанятого).
2. Раздел **Чат-боты → Создать** → заполните карточку, дождитесь модерации (до 48 рабочих часов).
3. После публикации: **Чат-боты → ⋮ → Настройки** → скопируйте **токен** (access token).

### 2. Настройте токен

```bash
copy .env.example .env   # Windows
# или
cp .env.example .env     # Linux/macOS
```

Откройте `.env` и вставьте токен:

```
BOT_TOKEN=ваш_токен_сюда
```

> ⚠️ Токен секретен — **не коммитьте** `.env` в репозиторий (он уже в `.gitignore`).

### 3. Запустите

**С графическим интерфейсом (рекомендуется):**

```bash
python gui.py
```

В окне нажмите **«▶ Запустить бота»**.

**Из командной строки (без GUI):**

```bash
python bot.py
```

## 🎯 Как добавить бота в канал

Чтобы бот выгрузил историю, он должен быть **администратором** канала/чата с правом **«Читать сообщения всех участников»** (`read_all_messages`).

1. **Сначала добавьте бота как подписчика/участника**: канал → «Подписчики» → «Добавить подписчиков» → найдите бота (по никнейму `@idИНН_bot` или ссылке) → «Добавить в канал».
2. **Затем назначьте администратором**: канал → «Администраторы» → «Добавить администратора» → выберите бота → включите нужные права → «Назначить администратором».

Как только бот получит права, он автоматически выгрузит всю историю.

> 💡 Если в поиске «Участники не найдены» — сначала откройте диалог с ботом в MAX (найдите его по никнейму и напишите ему), затем добавьте в канал.

## 🗂 Что попадает в выгрузку

Для каждого поста сохраняется:

| Поле | Описание |
|------|----------|
| `chat_id` | ID чата/канала |
| `mid` | Уникальный ID сообщения |
| `seq` | Порядковый номер |
| `sender_id` / `sender_name` | Автор |
| `timestamp` | Время (unix, мс) |
| `text` | Текст поста |
| `attachments_json` | Вложения |
| `url` | Публичная ссылка |
| `comments` | Кол-во комментариев (канал) |

Отдельно сохраняются комментарии к постам каналов. Посты дедуплицируются по `(chat_id, mid)`.

### Выходные файлы (папка `exports/`)

- `<chat>_<название>_posts.json` / `.csv` — посты;
- `<chat>_<название>_comments.json` / `.csv` — комментарии;
- `<chat>_<название>_report.xlsx` — Excel-отчёт;
- `<chat>_<название>_report.html` — HTML-отчёт с графиками;
- `attachments/<chat>/` — скачанные вложения.

## 🛠 Команды CLI

```bash
# Запуск в фоне (long polling)
python bot.py

# Ручная выгрузка конкретного чата
python dump_manual.py --chat 123456

python list_chats.py

python search_cli.py --query "новость" --date-from 2026-01-01 --date-to 2026-01-31
```

## 📝 Примечания

- **Long Polling** (`GET /updates`) подходит для локального запуска. Для продакшена MAX рекомендует **Webhook** (`POST /subscriptions`) — см. [документацию MAX](https://dev.max.ru/docs-api).
- API MAX отдаёт историю постов только если бот — администратор чата/канала с правом чтения истории.
- Запросы идут на `platform-api2.max.ru` по HTTPS (сертификат Минцифры).
